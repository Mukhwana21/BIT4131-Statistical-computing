# BIT 4131: Statistical Computing and Reporting

This repository contains a reproducible practical project for all 23 topics in
the BIT 4131 group-work brief. It demonstrates statistical concepts and
mathematical formulations, worked examples, analysis of a shared dataset,
expected outputs, interpretation, and visualizations in both Python and R.

The dataset is synthetic and is created specifically for teaching. It is not
evidence about real students.

## Project contents

- [`docs/topic_guide.md`](docs/topic_guide.md): theory, formulas, analysis
  questions, and interpretation guidance for each topic.
- [`data/student_performance.csv`](data/student_performance.csv): shared
  deterministic 240-record teaching dataset (generated by the Python script).
- [`python/run_all.py`](python/run_all.py): implementations for topics 1–23,
  tables, plots, and a generated Markdown results report.
- [`R/run_all.R`](R/run_all.R): corresponding implementations in R.
- [`python/generate_data.py`](python/generate_data.py): reproducible dataset
  generator.

## Run the Python analysis

From the repository root:

```bash
python -m pip install -r requirements.txt
python python/generate_data.py
python python/run_all.py
```

The runner writes topic-by-topic console output, figures to
`results/python/figures/`, and a summary report to
`results/python/report.md`.

## Run the R analysis

From the repository root, using R 4.1 or later:

```bash
Rscript R/run_all.R
```

The R runner uses base R and the recommended `stats` package, reads the same
CSV, and writes figures and a summary report to `results/R/`.

## Reproducibility

The data generator and analysis runners use fixed random seeds. All analysis
code reads the checked-in CSV; run the generator only when intentionally
recreating that dataset. Python package versions can be installed from
[`requirements.txt`](requirements.txt). The R runner prints errors rather
than silently substituting missing results.

## Reading the results

Start with the guide for each topic's assumptions and equations, then run either
language implementation. Numerical output may differ slightly across
implementations because random number generators and statistical routines
differ; conclusions should agree. Treat p-values as evidence relative to the
stated null model, not as the probability that a hypothesis is true.
